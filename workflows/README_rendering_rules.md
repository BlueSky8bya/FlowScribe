# FlowScribe 렌더링 규칙

## 렌더링 순서
```
raw text → [CLIFF] 제거 → marked.parse() → mergeUnclosedBrackets → mergeUnclosedQuotes → splitDialogueNarration → applyDialogueStyle → applyFocusLine
```

---

## 모델 출력 규칙

- 대괄호 블록 `[상태창]`은 반드시 한 단락 안에서 열고 닫을 것. 내부 줄바꿈 금지.
- 대화 따옴표는 반드시 같은 단락 안에서 닫을 것. 단락 경계에서 열린 채로 끊지 말 것.
- 대화는 곡선 따옴표 `" "` 사용. 직선 `"` 는 혼합 단락 분리가 안 됨.
- `[CLIFF]`는 반드시 단독 줄에, 대괄호 열고 닫아서 정확히 출력할 것.

---

## 따옴표 처리 기준

| 패턴 | 처리 |
|---|---|
| `"..."` 곡선 이중 (U+201C/D) | 대화 분리 + 첫글자 감지 |
| `'문장 내용'` 곡선 단일, 공백 포함 (U+2018/9) | 대화 분리 |
| `'단어'` 곡선 단일, 공백 없음 (U+2018/9) | 강조 표현으로 간주 — 분리 안 함 |
| `「...」` `『...』` 전각 | 대화 분리 + 첫글자 감지 |
| `"..."` 직선 (U+0022) | 분리 안 함 — 단락 첫글자일 때만 dialogue-line |
| `'...'` 직선 (U+0027) | 완전 제외 |

## 버그 발생 시 체크

1. DB `content` 컬럼 직접 조회 — `JSON.stringify`로 따옴표 종류 확인
2. `[CLIFF]` 형태 확인 — `[CLIFF]` / `[CLIFF\n` / 누락
3. JS `?v=N` 버전 최신인지 확인

## 알려진 모델 오작동 패턴

| 증상 | 원인 | 서버 대응 |
|---|---|---|
| 직선 `"` 대화 — dialogue-line 미적용 | 모델이 U+0022 사용 | 클라이언트: `renderProgressiveRaw`에서 단락/인라인 패턴 곡선 변환 |
| `[CLIFF]` 없이 콘텐츠가 중간에 끊김 | 본문이 maxLen 초과 → 토큰 한계 도달 | 프롬프트: maxLen 초과 시 즉시 [CLIFF] 강제. [CLIFF] 생성률은 모델 의존적 |
| `......` 등 점 연속이 본문에 남음 | 모델 출력 말미 garbage | STOP_PATTERNS에 `"......"` 추가 |
| 단락 끝 `.\n\n"` 패턴이 garbage 처리됨 | garbageTail이 정상 구두점을 쓰레기로 간주 | SAFE_CHARS에 공백·줄바꿈·따옴표 추가 |
